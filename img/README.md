# 작품 이미지 폴더

작품 하나당 폴더 하나입니다. **사진을 폴더에 넣기만 하면** 사이트에 나옵니다.
장수를 세거나 파일 이름을 맞출 필요가 없습니다.

```
img/
  photo01/           ← 작품 하나
    image01.jpg      ← 첫 번째 사진이 대표 이미지
    image02.jpg
    전시전경_02.jpg   ← 이런 이름도 괜찮습니다
  photo02/
  ...
  manifest.json      ← 자동 생성 파일. 손대지 마세요
```

## 사진을 추가·교체하려면

폴더에 넣거나 지우면 끝입니다. 배포할 때 `make-manifest.ps1` 이 폴더를 훑어
`manifest.json` 을 다시 만들고, 사이트는 그 목록을 그대로 따릅니다.

바로 확인하고 싶으면 직접 실행해도 됩니다.

```powershell
powershell -ExecutionPolicy Bypass -File make-manifest.ps1
```

### 규칙

- 확장자는 `.jpg .jpeg .png .webp .gif .avif`
- **순서는 파일 이름순**입니다. `image01.jpg`, `image02.jpg` … 식으로 두 자리를
  쓰면 의도한 순서가 보장됩니다. (`image2` 와 `image10` 도 숫자로 비교하므로 안전)
- **첫 번째 사진이 대표 이미지** — 작품 화면과 마우스오버 배경에 쓰입니다
- `manifest.json` 은 저장소에 올리지 않습니다(자동 생성물). 지워도 다시 만들어집니다

## 새 작품 폴더를 만들었다면

폴더만 만들어서는 안 되고, `script.js` 의 `WORKS` 배열에 한 줄을 넣어야 합니다.
제목·재료·연도는 사람이 정하는 정보라 자동으로 알 수 없기 때문입니다.

```js
{ row: 0, folder: "photo10", title: "작품 제목", meta: "Mixed media · 2026", desc: "" },
```

- `row: 0` — 사진 작업 표시(예전 궤도 방식의 윗줄). 영상 작업은 생략
- `desc` — 작품 화면 설명. 줄바꿈은 `<br>`

### count 는 이제 안 써도 됩니다

예전에는 `count: 3` 처럼 장수를 적어야 했습니다. 지금은 `manifest.json` 이
있으면 무시되고, 없을 때만(예: 갓 클론한 저장소) 예전 방식으로 쓰입니다.
남아 있는 `count` 값들은 그 대비용이라 지우지 않았습니다.

## 권장 사양

- 가로 1600px 이상, JPEG 품질 80% 안팎 (한 장당 300~500KB)
- 한 장이라도 25MB 를 넘으면 Cloudflare Pages 업로드가 실패합니다
